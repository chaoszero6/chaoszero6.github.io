reactive-ledger

Java 21Spring Boot 3.5MIT

A double-entry ledger service on Spring WebFlux, built to show the work I do at banks in code anyone can run.

  • Idempotent transfers: a client retry returns the original posting, and 25 racing retries with one key still move money exactly once.
  • Both accounts locked in a fixed order inside one R2DBC transaction, so no overdraft and no deadlock under 400 opposing concurrent transfers.
  • RFC 9457 problem documents for every business rejection.
  • Each request is one OpenTelemetry trace in Grafana Tempo, with every SQL step as a child span; metrics carry exemplars that link back to traces.
  • Provisioned Grafana dashboard: p50/p95/p99 by route, 4xx/5xx split, transfer outcomes, pool pressure, GC.
  • k6 open-model load test: 300 transfers/s with 0 errors and p99 99.5 ms, on a 2-core laptop also running the whole stack.

Shows: the same reactive, observability and performance skills as my day job, with tests and numbers you can reproduce.
